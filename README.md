# Dynamic Clinical Task Board (DOM Operations)

This project is a dynamic patient management board designed to practice and demonstrate core Vanilla JavaScript DOM manipulation techniques. The primary focus of this project is interacting with the Document Object Model, specifically creating, traversing, and removing elements dynamically.

## 🚀 Features & Concepts Applied

- **DOM Selectors:** Accessing elements using `querySelector` and `getElementById`.
- **Dynamic Styling:** Modifying CSS properties directly through JavaScript.
- **Content Modification:** Updating page content dynamically using `textContent`.
- **Attribute Management:** Setting custom attributes dynamically via `setAttribute`.
- **CSS Class Manipulation:** Managing styling classes conditionally using `classList.add()` to color-code patient statuses (e.g., Emergency, Follow-up, Examination).
- **Element Creation:** Generating new `div` and `button` nodes on the fly using `document.createElement()` and attaching them to the DOM.
- **DOM Traversal & Node Deletion:** Navigating the DOM tree from a child element (delete button) to its parent (`parentElement`) and successfully deleting specific records using the `.remove()` method.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
